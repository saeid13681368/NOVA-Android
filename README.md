# NOVA

NOVA portable source package.

## Current verified environment
- Python 3
- Android Termux
- Local web interface and PWA routes

## Start
From the NOVA project directory:

    python -m core.web_app

## Important
- AI provider credentials are not included in portable packages.
- Personal memory, logs, backups, and benchmark data are excluded.
- This package is a source bundle, not yet a cross-platform native installer.
- Other operating systems require separate installation and compatibility tests.
